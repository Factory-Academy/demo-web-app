# Customization Markers
Same markers as other templates. Key file renames:
- `src/models/item.ts` -> `src/models/{model}.ts`
- `src/models/widget.ts` -> `src/models/{secondary}.ts`
- `src/components/item-list.tsx` -> `src/components/{model}-list.tsx`
- `src/services/item-service.ts` -> `src/services/{model}-service.ts`
- `src/app/api/items/route.ts` -> `src/app/api/{models}/route.ts`
