# Demo Web App Template (Next.js/React/TypeScript)

SE reference hub for the `demo-web-app` template repository.

## What is this?
A minimal Next.js 14 application used as a starting point for personalized Factory AI sales demos. Generic models (Item, Widget) get renamed to domain-specific models during demo prep.

## Quick Links
- [Demo Flow](demo-flow) -- 15-min and quick timelines
- [Customization](customization) -- Marker replacement points
- [Demo Moments](moments) -- Available moments
- [Setup Guide](setup) -- `/demo-setup` instructions

## Tech Stack
Next.js 14, React 18, TypeScript 5, Jest

## Running Locally
```bash
npm install && npm run dev
```
Open http://localhost:3000.
